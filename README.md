# 4th-Year-Project

This repository contains the dataset collected from 4-probe station measurements for our final year project:

**"Investigation of Superconducting Quantum Amplifiers"**

Due to the size of the dataset, we provide the full data here instead of including it in the appendix of our written report.

## Project Members
- **Anxin Bei**
- **Zoe Qian**
- **Linuo Zhu**
- **Linyue Zhu**

## Contents
The dataset includes raw and processed data from our experiments using a 4-probe measurement station, supporting our analysis of superconducting materials and their properties in quantum amplifier contexts.

## Usage
Feel free to browse or download the data for reference. If you use this dataset in any derivative work, please credit our project appropriately.

## Context
This data was collected as part of our undergraduate final year project in EEE (2024–2025). For further details on the experimental setup, analysis, and conclusions, please refer to our written report.
